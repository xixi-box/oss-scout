**Make custom-score threshold filtering reject NaN thresholds.**

For custom-scored queries, `point.score <= score_threshold` is false when `score_threshold` is NaN. The cut never runs, so every point is returned. The base code and the local shard return no points for this input. Negate the greater-than comparison so NaN truncates the results.
